## 🚀 Selected Projects

### 🛠️ [Avero](https://github.com/shajiaalianwar55/Avero)

An AI-assisted home-maintenance platform designed to handle uncertainty safely, evaluate model behaviour systematically, and fall back to fixed safety rules when needed.

Some of the AI engineering principles implemented include:

- explicit abstention and escalation behavior
- structured model outputs
- safe-failure evaluation cases
- deterministic safety rules
- AI trace events for observability
- model and prompt versioning
- separation of model-generated outputs from authoritative deterministic logic

This project has been particularly useful for thinking about how AI systems should behave when they are uncertain or operating in safety-sensitive contexts.

---

### 📚 [Agentic AI Book Buddy](https://github.com/shajiaalianwar55/Agentic-AI-Book-Buddy)

A multi-agent recommendation system built using **Google ADK and Gemini**.

The system includes:

- preference extraction
- web search
- agent orchestration
- session state
- long-term memory
- explainable recommendations

Rather than relying only on ratings or popularity, the system builds a structured profile of why a reader enjoys particular books and uses that profile to generate recommendations.
